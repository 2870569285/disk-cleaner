# 磁盘清理助手（Disk Cleaner）

一个仅使用 Python 标准库的本地可视化磁盘清理工具，只清理白名单内的缓存与垃圾文件，不触碰系统文件、程序和个人文档。支持多盘扫描与删除前备份到其他盘。

## 功能特性

- 可视化界面：本地网页操作，显示各项目大小、文件数、风险等级，支持全屏
- 多盘扫描：自动枚举本地固定磁盘，可切换 C/D/E 等盘符分别扫描
- 白名单机制：可清理项目全部内置定义，删除接口不接受任意路径，杜绝误删
- 三级风险标签：安全 / 注意（建议先关闭对应程序）/ 谨慎（请确认后再清理）
- 删除前备份：可勾选备份到其他盘指定路径，自动按时间戳归档，保留原目录结构
- 空间预检：备份前检查目标盘剩余空间，空间不足的项目整项跳过
- 占用跳过：正在被使用的文件自动跳过并统计数量，不影响运行中的程序
- 本地运行：服务只绑定 127.0.0.1，不对外网开放

## 运行环境与依赖

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Windows 10 / 11（依赖 Win32 API 枚举磁盘，不支持 Linux / macOS） |
| Python | 3.8 及以上（开发验证于 3.10） |
| 第三方依赖 | 无。仅使用标准库（http.server、ctypes、shutil、json 等），无需 pip install |
| 浏览器 | Edge / Chrome / Firefox 等现代浏览器（界面需要 fetch、ES6 支持） |
| 权限 | 建议以管理员身份运行，清理系统级目录（如 Windows\Temp）需要管理员权限；无权限时对应文件会自动跳过 |
| 网络 | 无需联网；服务仅监听本机 127.0.0.1:8795 |

## 快速开始

1. 确认已安装 Python（命令行执行 `python --version` 可见版本号）
2. 双击 `启动清理工具.bat`，或在命令行执行 `python cleaner.py`
3. 浏览器会自动打开 `http://127.0.0.1:8795`
4. 选择盘符 → 勾选项目（或点「全选安全项」）→ 点击「删除选中项」→ 确认
5. 用完后在命令行按 Ctrl+C 停止服务

## 清理项目清单（系统盘）

| 项目 | 级别 | 路径 | 说明 |
| --- | --- | --- | --- |
| 用户临时文件 | 安全 | %LOCALAPPDATA%\Temp | 程序运行临时文件 |
| 系统临时文件 | 安全 | C:\Windows\Temp | 系统临时目录 |
| Windows 更新下载缓存 | 安全 | C:\Windows\SoftwareDistribution\Download | 已装更新的安装包残留 |
| 传递优化缓存 | 安全 | C:\Windows\ServiceProfiles\...\DeliveryOptimization\Cache | 更新分发 P2P 缓存 |
| 崩溃转储 | 安全 | C:\Windows\Minidump、MEMORY.DMP、CrashDumps | 蓝屏/崩溃诊断文件 |
| Windows 错误报告 | 安全 | C:\ProgramData\...\WER | 程序出错上报记录 |
| 系统更新日志 | 安全 | C:\Windows\Logs\CBS | 更新过程日志，按需重建 |
| DirectX 着色器缓存 | 安全 | %LOCALAPPDATA%\D3DSCache | 删除后自动重建 |
| 缩略图 / 图标缓存 | 安全 | %LOCALAPPDATA%\Microsoft\Windows\Explorer | 删除后自动重建 |
| pip 缓存 | 安全 | %LOCALAPPDATA%\pip\cache | 删除后装包需重新下载 |
| npm 缓存 | 安全 | %LOCALAPPDATA%\npm-cache、~\.npm | 删除后装包需重新下载 |
| 系统网络缓存 | 安全 | %LOCALAPPDATA%\Microsoft\Windows\INetCache | 系统组件联网缓存 |
| Chrome 浏览器缓存 | 注意 | Chrome User Data 下 Cache、Code Cache | 建议先关 Chrome；不影响密码/书签 |
| Edge 浏览器缓存 | 注意 | Edge User Data 下 Cache、Code Cache | 建议先关 Edge；不影响密码/书签 |
| 回收站 | 谨慎 | C:\$Recycle.Bin | 清空前确认无需恢复 |
| Windows.old | 谨慎 | C:\Windows.old（存在时才显示） | 删除后无法回退旧系统 |

非系统盘仅扫描：该盘回收站、Windows.old（如有）、根目录 Temp/tmp 文件夹（如有）。

## 常见问题

1. 清理后释放的空间比预期少？
   部分安全软件会把删除操作重定向到回收站兜底，清空回收站后才真正释放空间；清空前请先确认其中没有需要恢复的文件。
2. 显示「失败跳过 N 个文件」？
   多为正在使用中的文件，属正常现象，不影响系统运行。
3. 备份文件夹创建失败（拒绝访问）？
   可能是安全软件拦截或权限不足：可更换备份路径重试，或取消备份直接清理（文件通常会进回收站兜底）。
4. 备份文件如何管理？
   备份按 `备份路径\清理备份_时间戳\项目名\原目录结构` 归档，确认清理无误后可自行删除旧备份。
5. 端口被占用？
   编辑 cleaner.py 顶部的 `PORT = 8795` 改为其他端口。
6. 如何彻底移除本工具？
   直接删除工具文件夹即可，程序不写注册表、不装服务、不留残留。
